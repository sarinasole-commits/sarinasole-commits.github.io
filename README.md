# sarinasole-commits.github.io

个人小站，GitHub Pages 托管，地址：https://sarinasole-commits.github.io/

## 结构

| 路径 | 内容 |
| --- | --- |
| `/` | 首页导航 |
| `/puzzle/` | 拼图小游戏（上传照片生成打散拼图） |
| `/2048/` | 2048 小游戏 |
| `/tutorial/` | Muse 新手教程（阅读优化与内容补充版） |

## 约定

- 全部单文件页面，无外部依赖（无 Google Fonts、无外部脚本），国内网络和微信内均可打开。
- 新增页面时在对应目录下放 `index.html`，并在首页导航里加一卡。
